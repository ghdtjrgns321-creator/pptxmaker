# 6. 지도와 상태 — 현재를 기계가 쓴다

```
 [ 지도 ] ◀── 코드·SKILL.md에서 추출
 [ 상태 ] ◀── 계약·pptx·렌더 대조
```

## 6-1. 왜 손으로 안 쓰나

한 문서가 스스로 *"지금 어떻게 도나의 단일 출처"*라 선언한 채, 이미 폐기된 구조를 **6일 동안**
설명하고 있었다. 그걸 읽고 답한 것이 계속 어긋났고, 원인을 찾는 데 시간이 갔다.

**손으로 쓴 지도는 갱신을 잊는 순간 거짓말이 되고, 그 거짓말은 읽는 쪽을 없어진 곳으로 보낸다.**

## 6-2. `scripts/make_map.py` (315줄) → `docs/MAP.md`

```bash
uv run python scripts/make_map.py     # exit 0이어야 한다
```

사람 문장이 0줄이고 전부 코드·SKILL.md에서 뽑는다.

| 뽑는 곳                                                 | 무엇                                                             | 위치       |
| ------------------------------------------------------- | ---------------------------------------------------------------- | ---------- |
| `SKILL_MAIN` = `pptmaker/SKILL.md`                      | `## 파이프라인` 다음 첫 코드블록 **원문 그대로**                 | `:38-42`   |
| `CODE_DIRS` = `pptx-build/scripts`                      | `*.py` ast 파싱 → 줄 수 · 공개 함수                              | `:60-74`   |
| `AUDIT` = `goldenfab/audit.py`                          | `^def check_\w+`를 `generic_checks` 본문·타 스크립트 호출과 대조 | `:78-95`   |
| `DOC_DIRS` = `docs`, `.claude/skills`, `.claude/agents` | `*.md` 줄 수 · `git log -1` 날짜 · 죽은 참조                     | `:189-221` |

### exit 1을 내는 경고 3종

| #   | 조건                                                                                   |
| --- | -------------------------------------------------------------------------------------- |
| 1   | 절차가 부르는 이름(`*.py`·`*.ps1`·스킬)이 rglob으로 안 잡힘                            |
| 2   | `check_*` 함수가 `generic_checks`에도 없고 타 스크립트 호출도 없음 → **★ 호출자 없음** |
| 3   | **역사가 아닌** 문서가 존재하지 않는 심볼·파일을 백틱으로 가리킴                       |

경고 2가 이 저장소의 핵심 방어다. *"규칙이 있어도 러너에 안 물리면 없는 규칙"* — 채움률 FAIL
9건이 규칙만 있고 배선이 없어 오래 방치된 실측에서 나왔다.

### 면제 — 조용한 통과를 만드는 자리

| 면제             | 내용                                                                                                                                |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `is_history()`   | 파일명 `YYYY-MM-DD-*` · `handoff-*` · `CHANGELOG.md` · 경로에 `superpowers` → 죽은 참조 있어도 경고 없음                            |
| `TOMBSTONE` 12개 | `아카이브 · _archive · 옮겼 · 삭제 · 소멸 · 없어진 · 없앴 · 물러났 · 폐기 · 사라졌 · 지웠 · 미배선` — **앞뒤 1줄** 안에 있으면 면제 |
| 확장자 스킵      | `.md .yaml .yml .pptx .png .tsv .json` 참조는 죽은 참조 판정 대상 아님                                                              |
| `EXTERNAL`       | `pptx. inspect. XL_ MSO_ PP_ Pt. Inches. Emu. np. plt.`                                                                             |

역사 문서는 **그때의 사실**이라 죽은 참조가 정상이다. 그래서 면제한다. 문제는 그 면제가
살아있는 문서까지 덮는 경우다(아래 6-4).

### 산출물 — `docs/MAP.md` (112줄)

§1 절차 원문 + 이름 실재표(4/4 O) · §2 살아있는 코드 10파일 **2,630줄** · §3 검사 12종 배선 ·
§4 문서 28건(살아있음 9 / 역사 19) · §5 경고.

**검증(2026-08-04)**: 생성기를 dry-run으로 다시 돌려 출력 바이트가 동일함을 확인했다.
지도는 워킹트리 현재 코드와 동기 상태이며 경고 0건이다.

## 6-3. `scripts/deck_state.py` → `STATE.md`

지도가 **하네스**의 현재라면, 이건 **그 덱**의 현재다.

이 파일이 필요한 이유는 목차 계약 다음부터 산출 직전까지 **아무것도 파일로 안 남았기**
때문이다. 어떤 형태를 왜 골랐는지, 무엇을 반려당했는지가 세션과 함께 사라졌고, 다음 덱에서
같은 반려가 다시 나왔다.

STATE.md에 쌓이는 것: 지금 몇 단계인지 · 장마다 어떤 형태를 왜 골랐는지 · **무엇을 반려당했고
그걸 하네스로 내릴지**. 마지막 칸이 `미정`으로 남아 있으면 `check`가 exit 1을 낸다.

판정 상세는 [5장](5_GATES.md)에 있다.

## 6-4. 지도가 못 보는 것

`MAP.md §5 경고: 없음`은 **검사 범위 안에서만** 참이다. 실측으로 확인된 사각지대 셋:

| #   | 사각지대                                       | 결과                                                                                                                                                                                                                                                             |
| --- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `CODE_DIRS`가 `pptx-build/scripts` **한 곳뿐** | `scripts/`의 세 스크립트(`make_map`·`deck_state`·`check_outline` 724줄)와 `_plan/verify_no_archive_refs.py`(146줄)가 §2 인벤토리에 **안 나온다**. `pptx-visuals/scripts`도 밖이라 **미배선 1,204줄이 지도에 뜨지 않는다.** §2의 "2,630줄"은 하네스 전체가 아니다 |
| 2   | `DOC_DIRS`에 `CLAUDE.md`·`README.md`가 없다    | 두 문서의 스테일 서술을 지도가 **구조적으로 못 잡는다**                                                                                                                                                                                                          |
| 3   | 확장자 스킵 + TOMBSTONE 창 ±1줄                | *"`grid.py`의 `pitch`·`track`은 **단일 출처다**"* 같은 현재형 문장이, 같은 줄에 "사라졌다"가 있어 통과했다                                                                                                                                                       |

3번이 실제로 남긴 것 — 살아있는 스킬 문서 6곳이 **없는 것을 현재형으로 설명하고 있다**:

| 문서가 부르는 것                                  | 실물                                             |
| ------------------------------------------------- | ------------------------------------------------ |
| `_archive/` (4개 문서가 위치를 지정)              | 디렉터리 자체가 없음                             |
| `goldenfab/grid.py` · `layouts.py` · `dense.py`   | 없음                                             |
| `pitch` · `track` (3개 문서가 "단일 출처"라 부름) | 저장소 전체에 정의 0건                           |
| `dense.hero_card` 등 부품 5종                     | 없음                                             |
| `brand-kit.yaml` = "이 파일만 고치면 전체 반영"   | 실전 조판·게이트는 `deckkit/brand.yaml`을 읽는다 |
| `archetype-catalog.md`의 L26~L30 렌더러           | 없음 — 문서 스스로 건 철칙 ①의 자기 위반         |

**지도를 권위로 세운 것 자체는 옳았지만, 지도의 분모가 하네스 전체가 아니다.** 이것이 이
저장소에 남은 가장 큰 구조적 공백이다([8장 한계](8_TEST-DECISIONS.md)).

## 실증 — 지도가 죽은 참조를 잡는 순간

2026-08-03에 `goldenfab`의 `layouts`(250줄)·`dense`(273줄)·`grid`(84줄)를 지웠다. 지우자마자
`make_map.py`를 돌렸더니:

```
생성: docs/MAP.md — 경고 15건
★ .claude/skills/pptx-build/SKILL.md: 없는 참조 `layouts.py`
★ .claude/skills/pptmaker/SKILL.md: 없는 참조 `goldenfab.dense`
...
```

문서 6개가 방금 지운 모듈을 여전히 현재형으로 설명하고 있었다. **코드를 지우면 산문이
거짓말을 시작한다** — 그 15건을 고쳐 exit 0을 만든 것이 그날 작업의 마지막 단계였다.

그런데 같은 검사가 `pitch`·`track`은 못 잡았다. 그 문장들이 TOMBSTONE 낱말과 같은 줄에
있었기 때문이다. 지도는 **자기가 보는 범위 안에서만** 정직하다.

## 8-2. 변동성 측정 — 같은 장을 3번씩

**방법**: 같은 계약·같은 재료·같은 프롬프트(출력 파일명만 다름)로 S7·S10을 각 3회. 매 회차는
**새 컨텍스트**이고 기존 답·다른 회차·골든을 못 열게 막았다. 뼈대(경로·판형·저장)를 고정해
보일러플레이트 차이가 변동으로 잡히지 않게 했다.

|            | S7 3회                    | S10 3회         |
| ---------- | ------------------------- | --------------- |
| 도형       | 109~111 · **변동계수 1%** | 142~188 · 13%   |
| 시각 요소  | 42~47 · 5%                | 57~92 · **22%** |
| 글자       | 774~866 · 5%              | 648~852 · 11%   |
| 블록 조합  | 1종 / 3회                 | 2종 / 3회       |
| 게이트     | 3/3 결함 0                | 3/3 결함 0      |
| 토큰 밖 색 | 0                         | 0               |

**변동의 크기를 정하는 것은 하네스가 아니라 재료다.** S7은 순서(8단계)와 개수(흐름 7종)가
재료에 박혀 있어 3회가 같은 4구획으로 수렴했다. S10의 "29종"은 순서 없는 집합이라 셋으로
갈렸다. 반면 감리 지적 빈도 막대(147을 1.0으로 정규화, 최댓값만 accent)는 **3회 전부 동일**
했다 — 재료에 크기가 이미 있는 자리다.

**수치는 안 흔들렸다.** 3회 전부 `147/80/23/22/20/20/12/3/2`와 `4·5·5·6·5·4`로 동일했고
지어낸 수치는 없었다.

**계약의 어긋남을 3/3이 독립적으로 잡았다.** 계약은 「시나리오 20종」인데 재료가 뒤에
갱신되어 24종이 됐고, 세 회차 모두 재료를 따르고 그 사실을 보고했다.

## 8-3. `Panel` 삭제 전후 — A/B

프롬프트를 글자 단위로 같게 두고 **도구 하나만 지운 뒤** S7을 다시 3회 만들었다.

|            | 도형 | 시각 |    글자 | 커넥터 | 큰 단색 면 / 본문 |
| ---------- | ---: | ---: | ------: | -----: | ----------------: |
| 완성본     |  111 |   42 |     846 |      3 |            **0%** |
| 1차 r1     |  109 |   44 |     866 |      6 |           **94%** |
| 1차 r2     |  111 |   42 |     862 |      4 |               93% |

빈 자리가 허전해지지 않고 **내용으로 찼다.** b1·b2는 1차에 아예 없던 인코딩을 만들었다 —
분개 라인 수 `66.7/16.6/5.8/1.1%` 비율 막대, 기표 일자 가중 `4·3·2배` 막대, 8단계를 가로
체인으로 눕히고 「이상 데이터 주입」만 회색으로 꺼서 *이 장에서 안 도는 단계*를 표시(두 회차가
독립적으로 같은 판단).

**단 3회가 다 오르지는 않았다.** b3는 1차와 같은 수준이다. **2/3 상승 · 1/3 제자리**가 정직한
결론이다.

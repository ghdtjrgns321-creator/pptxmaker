**같은 프로젝트를 소개하는 PPT를, 장마다 다른 형태로, 서식만 일관되게 찍어내는 공장이다.**
템플릿은 색·글꼴·여백·페이지 골격만 소유하고 **장 구성은 소유하지 않는다** — 그것이 이 저장소가
"36장이 동일한 4카드"를 두 번 겪고 내린 결론이다.

---

## 시스템 한눈

```
 재료(사용자가 미리 정리)              계약                        덱
 ┌──────────────────┐      ┌────────────────────┐      ┌─────────────────┐
 │ README.md        │      │ 01.5_outline.md    │      │ deck.py         │
 │  ## 3-2 헤딩     │─────▶│  장 제목(재료 뎁스)│─────▶│  header(s,10,   │
 │  표 9행 · 수치   │ 인터뷰│  헤드라인(확정)    │ 조판  │   "Ⅲ", 제목)   │
 │                  │      │  부(간지) 5행      │      │  blocks 8종     │
 └──────────────────┘      │  채록 원문         │      │  kit 원시도구   │
          │                └────────────────────┘      └────────┬────────┘
          │                          │                          │
          │   check_outline.py       │      check_deck.py       ▼
          └───제목이 재료에서 나왔나──┘   ┌──문구·좌표가 계약대로인가──┐
                                          │  하드페일 9종 · 보고 1종  │
                                          └───────────┬──────────────┘
                                                      │
              render_deck.ps1 ─── PNG 전장 ──▶ 눈검증 ◀── 진짜 게이트
                                                      │
              score_deck.py ─── audit 12종 ──▶ 참고 채점
                                                      │
              deck_state.py ─── STATE.md ──▶ 단계·반려·획일화
```

세 화살표(재료→계약→덱)가 각각 기계로 대조된다. **다만 자동으로 도는 것은 없다** — 프로젝트 훅이
0개라 전부 사람이 실행한다(→ [8장 한계](8_TEST-DECISIONS.md)).

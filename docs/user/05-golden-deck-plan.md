## 리스크와 대비

- **가상 수치가 예쁘게 설계되는 함정** → 팩트시트 단계에서 실제 분포처럼 지저분한 숫자(78/92류)로 강제.
- **brand-kit 확장 필요**(display 타이포 등) → 단일 출처 원칙 유지: brand-kit.yaml에 추가하고 골든 스크립트도 그 파일을 읽는다.
- **역설계 중 골든과 공장의 이중 유지보수** → Phase 2 완료 시 golden/ 스크립트는 동결(기준 원본), 수정은 공장 쪽만.

## 이월: 콘텐츠 패스 (Phase 1 말 문구 일괄 리뷰와 병합)

승인 기준을 "UI·레이아웃 먼저, 단어·문장은 나중에 일괄"로 운영 중(2026-07-10 확정). 이월 항목:

1. **용어 번역 패스** — 팩트시트 원문 용어(1홉·traverse·E3·clarify 등)를 독자 언어로 바꾸는 단계가 파이프라인에 없음. 내부 식별자 금지어 목록을 만들어 오딧에 추가.
2. **독자 질문 게이트** — 장마다 "이 장이 답해야 할 질문"(예: 판단트리를 누가 어떻게 만들었나)을 계약에 박고, 문장이 실제로 답하는지 검수. 서식 오딧만으로는 hollow 설명을 못 잡는다(S6에서 실증).
3. **구축 설명 역할분리 결정(A/B)** — A: S6은 흐름만, 구축 상세(용어사전·판단트리 제작기)는 Part Ⅲ에 장 추가(pull). B: S6을 기술 총람으로 재정의. 문구 패스 때 결정.

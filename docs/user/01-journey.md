각 버전이 무엇을 고쳤고, 무엇이 해결되지 않은 채 다음 버전으로 넘어갔는지를 기록한다.

## 여정에서 보이는 패턴

1. **콘텐츠 트랙은 수렴했다.** v1(창작) → v2(외주) → v3(직접 추출 + 검증)으로 갈수록 나아졌고, v3 방식은 실측 근거(A/B 대조)로 확정됐다. 이 트랙은 더 고칠 것이 없다.
2. **시각 트랙은 발산했다.** v3 게이트 8종 → v4 게이트 3종 추가·방법론 4종 조합, 매번 "증상 하나 → 규칙 하나"를 더했지만 "없어 보임"은 남았다. 규칙이 쌓일수록 유지보수 대상만 늘었다.
3. **멈춘 이유:** 2026-07-09 McKinsey 리포트와의 전 장 실측 대조(→ [02-failure-analysis.md](02-failure-analysis.md))에서, 남은 갭의 다수가 규칙으로 도달할 수 없는 종류임이 확인됐다. 그래서 규칙 추가를 중단하고 골든 덱 방식(→ [03-golden-deck.md](03-golden-deck.md))으로 전환한다.

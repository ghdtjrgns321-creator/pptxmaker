# pptmaker 사용자 문서 — 목차

pptmaker는 내 프로젝트를 소개하는 B2B 셀링 PPT를 일관 서식으로 찍어내는 서식 공장이다.

## 현재 상태 요약 (2026-07-09)

- 파이프라인 골격(추출 → 구성 → 빌드 → 검수)은 유지한다. 문제는 골격이 아니라 시각 품질의 수렴점 부재였다.
- v4까지의 "증상 → 규칙 추가" 루프를 중단하고, **골든 덱(수동 디자인) → 공장 역설계** 방식으로 전환하기로 결정했다.
- 2026-07-09 grilling 인터뷰로 실행 계획 확정: 흰 본문 + 다크 간지, 가상 프로젝트(전표 리스크 스코어링) 견본 덱 17장, Phase 0~4. 미결정 사항 없음 — Phase 0(팩트시트·레퍼런스 크롭)부터 착수 가능.

# NotebookLM 투입용 프롬프트 템플릿 (v2 — 보고서형)

아래를 복사해 NotebookLM에 붙여넣는다. `<프로젝트명>`만 바꾼다.
**서식 지시(색·좌표·배경·폰트)는 넣지 않는다** — Claude Code가 재빌드하며 버려진다.
v1(슬라이드 요약형)의 한계: 슬라이드당 ~150단어 재료로는 컨설팅 보고서 밀도(250~400단어)가
안 나온다(2026-07-08 실측: 원문 1,464단어/10섹션 → 덱 중앙값 143단어로 재료 전량 소진).
**슬라이드 대본이 아니라 상세 보고서**를 요구해야 재료가 풍부해진다.

---

<프로젝트명> 소스를 근거로, B2B 구매 담당자를 설득하는 상세 제안 보고서를 작성해줘.
슬라이드 요약이 아니라 컨설팅 보고서 수준의 서술형 문서로, 섹션당 아래 요소를 채워줘.

섹션 구성(각 섹션 = 슬라이드 1장의 재료):
문제 제기(2~3섹션) → 솔루션·작동 방식(3~4섹션) → 차별점(2~3섹션) → 성과·증거(2~3섹션) → 확장 로드맵(1~2섹션)

각 섹션에 반드시 포함:
1. 헤드라인 한 줄 + 거버닝 메시지(결론 요약) 한 줄
2. 배경 서술 3~5문장 — 왜 이 주제가 중요한지, 업계 통념·현황 통계 포함
3. 핵심 주장 3~4개, 각 주장마다 근거 2~3문장 서술(불릿 한 줄로 끝내지 말 것)
4. 등장하는 전문 용어의 정의 한 줄 (예: "홀드아웃: 모델이 정답을 못 보게 격리한 평가셋")
5. 정량 데이터: 수치·비율·건수를 최대한 많이, 각 수치에 출처(소스 문서명) 표기
6. 방법론·프로세스는 단계별로 상세히 (입력→처리→출력, 각 단계에서 무슨 일이 일어나는지)
7. 예상 반론이나 한계 1개 + 그에 대한 대응 (신뢰를 만드는 균형 서술)
8. 가능하면 비교 벤치마크 (도입 전/후, 경쟁 방식 대비, 업계 평균 대비)

작성 규칙:
- 없는 성과·기능·수치를 지어내지 말 것
- 표로 정리 가능한 비교·스펙은 표로, 추세·비중은 수치 나열로 명시
- 대학 발표 스타일이 아니라 회계법인·컨설팅펌 보고서 문체로
- 분량 제한 없음 — 길수록 좋다

## 변주 (3~5개 초안을 다르게 뽑는 법)

1. 기본(위 프롬프트 그대로)
2. "+ 특히 도입 효과·ROI·비용 절감 관점을 심층으로"
3. "+ 특히 기술 아키텍처·구현 상세를 심층으로"
4. "+ 특히 경쟁 대비 비교와 리스크·반론 반박을 심층으로"
5. "+ 특히 고객 시나리오(도입 전/후 하루)를 심층으로"

산출물은 마크다운/텍스트로 복사해 `input/<프로젝트명>/` 폴더에 저장한다 — pptmaker가 여기서
읽는다. (pptx 다운로드는 비추천 — 슬라이드 전체가 이미지로 구워져 텍스트 추출이 안 됨)

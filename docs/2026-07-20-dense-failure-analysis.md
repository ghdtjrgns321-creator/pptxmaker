## 2. 근본 원인 (왜 쓰레기가 나왔나)

셋 다 한 뿌리 — **"압축 헤더 + 밴드 + hero_card 4장" 템플릿을 전 장에 기계 강제.**

- **원인 #1 (치명) — 골든 도해를 재사용 않고 조악하게 재드로.**
  사용자의 애초 의도는 *"좋은 골든 도해는 그대로 두고 밀도만 올려라"*. 나는 반대로
  **템플릿을 지키려고 도해를 버리고 다시 그렸다** → 원본보다 품질 하락. 골든 도해는
  수 회 반려 끝에 나온 자산인데(S9 트리 색 인코딩, S14 점선=확률, S16 경계 문법) 그걸
  40분짜리 재드로로 대체 = 다운그레이드.
- **원인 #2 — 4카드 강제.** 4개가 진짜 병렬인 장(s06 4기술·s08)만 4카드가 맞다.
  비교장(s14)·경계장(s16)·문제정의(s04)·스크린샷(s10)은 4병렬이 아닌데 우겨넣음 →
  억지 4번째 카드 + 골든 원 레이아웃 파괴.
- **원인 #3 — 카드 내용 부실화.** 억지 카드를 채우려 뒤 장일수록 불릿을 얇게 지어냄.
- **메타 원인 — 크랭크 모드 + 불완전 셀프체크.** "쭉 이어가자"에 기대 장마다 사용자 확인
  없이 찍어냄. 내가 만든 §8 셀프체크는 **표면**(검은 바·죽은 여백·캡션 겹침)만 봤고
  **구조**(도해 충실도·템플릿 강제·내용 깊이)는 안 봤다.

## 3. 재발 방지 규칙 (교정된 SPEC)

### R0. 기본 개편 = 최소 손질. 구조 재편은 예외.
사용자 최초 불만은 **큰 헤더 + 검은 바 + 일부 스카스한 장**이었지 도해가 아니었다.
그러므로 대부분 장의 dense 개편 = **(a) 28pt 헤더 → 압축 헤더 (b) 검은 전폭 바 제거
(c) 진짜 빈 곳만 채움.** 골든 도해·레이아웃은 **유지**. "밴드+4카드" 전면 재편은 s06처럼
*원래 스카스하고 + 내용이 4병렬*인 장에만.

### R1. 골든 도해는 재사용, 재드로 금지 (치명 규칙).
- 그 장 `sNN_variants.py`의 도해 함수를 **import해서 호출**하거나, 부득이하면 **좌표만
  옮겨 복사**(로직·색·도형·디테일 100% 보존). 새 드로잉 코드로 다이어그램을 다시
  그리기 시작하면 **멈춘다.**
- **검증**: dense 도해가 골든 도해와 도형 수·디테일이 같아야 함. 다르면 재드로한 것 = FAIL.
- 합격 장(s08·s09·s12)이 바로 이 방식. 그대로 본받을 것.

### R2. 4카드는 콘텐츠가 진짜 4병렬 peer일 때만.
- 4개 대등 항목이 아니면 4카드 금지. 골든 원 레이아웃(2패널·3열·도해+주석)을 밀도만 올려 유지.
- 억지 4번째 카드·억지 배지 숫자 맞추기 금지.

### R3. 카드/텍스트 밀도는 s06·s08 밴드가 하한. 뒤로 갈수록 얇아지면 FAIL.
- 못 채우면 그 카드는 존재하면 안 됨. 내용은 골든 원문 근거만(창작 0).

### R4. 장 착수 전 구조 게이트(그리기 전에 판정).
1. 이 골든 장에 잘 만든 도해가 있나? → **있으면 재사용**(R1). 재드로 금지.
2. 콘텐츠가 4 대등 항목인가? → **아니면 4카드 금지**(R2). 골든 레이아웃 유지.
3. 이 장이 원래 스카스한가? → 아니면 최소 손질(R0)로 끝.
4. 제시 전: 도해가 골든과 같나 / 4카드 억지 아닌가 / 카드 내용 s08급인가 — 셋 다 Y여야 제시.

### R5. 크랭크 금지. 장마다 렌더 → 사용자 확인 → 다음. 한 번에 몰아 찍지 않는다.

## 1. 존 구조 — 시선 여정

```
┌────────────┐  ┌──────────────────────────────────────┐  ┌────────────┐
│ ■ WHY 바   │  │ ■ HOW 바 (제목+부제)                  │  │ ■ IMPACT 바│
├────────────┤  ├──────────────────────────────────────┤  ├────────────┤
│ [컨테이너] │  │  ●──── Hackathon 프로세스 ────●      │  │ [컨테이너] │
│ (AS-IS 필) │  │ ┌STEP1 카드┐→┌STEP2 카드┐→┌STEP3┐   │  │ 행1 (아이콘│
│ 행×5       │  │ │동형 해부 8│ │  동일    │ │동일 │   │  │  +제목+설명│
│ (아이콘+구)│  │ │요소       │ │          │ │     │   │  │ ▼          │
│  ▼ 전환    │  │ └───────────┘ └──────────┘ └─────┘   │  │ 행2 ▼ 행3  │
│ (TO-BE 필) │  │  * 각주                               │  │ ▼ 행4      │
│ 행×3       │  │ [체인 스트립: 노드×5 → 화살표×4]      │  │            │
├────────────┤  └──────────────────────────────────────┘  ├────────────┤
│ ■ 결론 바  │                                            │ ■ 결론 바  │
└────────────┘  ┌──────────────────────────────────────────┴───────────┘
                │ [하단 스트립: ■배지 » (원아이콘+제목+불릿×3)×3 │ 코멘트] │
                └──────────────────────────────────────────────────────┘
■=primary 다크 필 · ●=다크 원형 노드 · ▼=accent 삼각형
```

시선 여정: 좌 레일(문제 AS-IS→TO-BE, 세로 하강) → 중앙(프로세스 1→2→3, 가로 진행)
→ 우 레일(효과 직원→전사, 세로 상승 위계) → 하단(사례 증거). 존마다 흐름 방향이 있고
화살표·삼각형이 그 방향을 명시적으로 인코딩한다 — 나열이 아니라 관계.

## 3. 동형 반복 패밀리 (골든 결함 #7의 교정 문법)

| 패밀리     | 멤버 수 | 내부 해부 (멤버 전원 동일)                                                                                                       |
| ---------- | ------- | -------------------------------------------------------------------------------------------------------------------------------- |
| STEP 카드  | 3       | 원형 배지 → 제목 → 라이트 배너 → 대형 아이콘 → 설명 2행 → `주요 활동` 라벨+룰 → 불릿 3~4 → `산출물 예시` 라벨+룰 → 아이콘 칩 3~4 |
| 좌 레일 행 | 5+3     | 아이콘 + 명사구(1~2행)                                                                                                           |
| 우 레일 행 | 4       | 아이콘 + 제목 + 설명 2행 (행 사이 ▼)                                                                                             |
| 하단 섹션  | 3       | 원형 아이콘 + 제목(+괄호 태그) + 불릿 3                                                                                          |

패밀리 4개, 최소 멤버 3. 멤버 간 아이콘 유무 혼재 없음(전원 있음). 불릿 수만 ±1 허용 진폭.

## 4. 타이포 사다리 — 비율 박제 → 우리 pt 매핑

앵커: 존 헤더(잉크 27px) = brand-kit `compact: 19pt` (파일럿 v3에서 이미 사용).
환산계수 19pt/27px = 0.70 → 이하 전부 이 계수로 도출.

| 위계         | 레퍼런스 잉크 | 비율 | 우리 pt        | 용처                                   |
| ------------ | ------------- | ---- | -------------- | -------------------------------------- |
| 존 헤더      | 27px          | 1.00 | **19 bold**    | 존당 1개, 상단 바                      |
| 카드 제목    | 23px          | 0.85 | **16 bold**    | 동형 카드 제목                         |
| 섹션·행 제목 | 18~20px       | 0.70 | **13~14 bold** | 도해 섹션 타이틀, 레일 행 제목         |
| 배너·라벨    | 16px          | 0.59 | **11 bold**    | 라이트 배너, `주요 활동`류 accent 라벨 |
| 결론 바·본문 | 13~14px       | 0.50 | **9.5~10**     | 불릿, 존 결론 바                       |
| 칩·캡션      | 10px          | 0.37 | **8**          | 아이콘 칩 라벨, 각주                   |

대역: 본문 8~16pt + 존 헤더 19pt 예외. 잉크 대비비 2.7:1 → pt 대비비 19/8 = **2.4:1 상한**.

## 7. 주의 (미검증·비적용)

- 레퍼런스는 2.12:1 화면이라 절대 밀도(82블록)를 16:9에 그대로 요구하면 과밀 —
  면적 환산 시 ~69블록 상당. R4 임계는 핸드오프의 40~60단위 + 도해 존을 정본으로 유지.
- 레퍼런스의 네이비·밝은 파랑은 **색이 아니라 역할**만 가져온다(§2 다크 3역할, §5 R11).
  색 리터럴은 brand-kit 토큰만(핸드오프 §4).
- 본문 불릿 잉크 13px는 행 피치 역산 추정치(`미검증` — 2행 걸침 오염). R3 판정은
  우리 pt 대역으로 하므로 판정에는 영향 없음.
- 크롭 검증 산출물: `golden/_pilot_s06/_ref_crops/` (존별 4장).

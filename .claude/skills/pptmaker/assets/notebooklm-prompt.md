# NotebookLM 투입용 프롬프트 템플릿

아래를 복사해 NotebookLM에 붙여넣는다. `<프로젝트명>`만 바꾼다.
**서식 지시(색·좌표·배경·폰트)는 넣지 않는다** — Claude Code가 재빌드하며 버려진다.
같은 노트북에서 관점을 바꿔 3~5회 생성한다(아래 변주 참고).

---

<프로젝트명> 소스를 근거로, B2B 구매 담당자를 설득하는 셀링 슬라이드 내용을
10페이지 내외로 구성해줘.

- 각 슬라이드는 헤드라인 한 줄 + 그 아래 거버닝 메시지(결론 요약) 한 줄로 시작
- 문장 끝에 마침표를 찍지 말 것
- 근거 있는 수치·데이터를 최대한 포함하고, 수치에는 출처(소스 문서명)를 붙일 것
- 없는 성과·기능을 지어내지 말 것
- 스토리 흐름 힌트: 문제 제기 → 솔루션 → 핵심 기능 → 차별점 → 성과·증거 → 다음 단계
- 대학 발표 스타일이 아니라 컨설팅 보고서처럼 분석·근거가 빽빽한 문서형으로
- 비교·스펙은 표로, 추세·비중은 차트(수치 명시)로, 프로세스는 단계 목록으로 표현

---

## 변주 (3~5개 초안을 다르게 뽑는 법)

1. 기본(위 프롬프트 그대로)
2. "+ 특히 도입 효과·ROI 관점을 중심으로"
3. "+ 특히 기술 아키텍처·차별점을 중심으로"
4. "+ 특히 경쟁 대비 비교와 리스크 반박을 중심으로"
5. "+ 특히 고객 시나리오(도입 전/후) 스토리를 중심으로"

다운로드한 pptx는 `input/<프로젝트명>/` 폴더에 모아둔다 — pptmaker가 여기서 읽는다.

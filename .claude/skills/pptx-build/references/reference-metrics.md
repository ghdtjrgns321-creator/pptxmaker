# 레퍼런스 실측 — BCG 기관 덱 (글자크기·밀도·구성)

출처: NYCHA "Key Findings and Recommendations" (BCG, 2012), 112p 중 본문 111슬라이드 측정.
페이지 = 10.5 × **7.5 in** → 우리 캔버스(7.5in 높이)와 폰트가 **1:1** 매핑된다.

## 글자 크기 (pt, 측정 median)

| 요소                       | pt      | 비고                                      |
| -------------------------- | ------- | ----------------------------------------- |
| 제목(action title)         | **24**  | 매우 일관(18~24). 2줄 긴 제목만 18        |
| 부제(descriptive subtitle) | **18**  | 제목 아래 설명 한 줄, 종종 리드 단어 밑줄 |
| 본문 불릿                  | **12**  | 최빈. 강조 리드 문장은 14                 |
| 컬럼/박스 헤더             | 14~16   | bold                                      |
| 서브 불릿(–)·캡션·라벨     | 8~10    | 들여쓴 2단계                              |
| 각주·출처·파일명           | **7~8** | 하단                                      |

→ 우리 brand-kit 적용값: section(제목)=24, sub(부제)=15, head(컬럼)=16, body=13, caption=9, foot=8.
  (본문은 우리 슬라이드가 더 넓어 12→13으로 약간 상향)

## 텍스트 밀도

- **단어/슬라이드: median 197** (p25 145 · p75 252 · max 484). 스타트업 피치의 3~4배.
- 텍스트 면적 커버리지 **median 35%**.
- → 우리 목표: 셀링용이라 상한을 낮춰 **슬라이드당 120~200 단어**. "여백 많은 한 줄" 금지.

## 내용 구성(나열 방식)

1. **액션 제목**(결론 문장) + **설명 부제**(한 줄) → **이중룰**
2. 본문은 **중첩 불릿**: 최상위 `•`(12pt) + 하위 `–`(들여쓰기, 10~12pt)
3. 여러 개의 **그룹 블록**(굵은 리드 문장 : 하위 근거들)로 묶어 밀도를 만든다
4. 핵심 수치·키워드는 **인라인 강조**(우리는 `**...**`=accent 볼드)
5. 정량 슬라이드 하단에 **출처선**, 참조는 **각주**(7~8pt)로 하단에
6. 푸터: 좌 파일/문서명 · 중앙 워드마크 · 우 페이지 · 우측 세로 저작권

## 함의 (하네스 규약)

- 큰 글자·넓은 여백 = 피치 템플릿(AI티). 작은 글자·높은 밀도·중첩 구조 = 기관 문서.
- 한 슬라이드에 한 메시지는 유지하되, 그 메시지를 **근거로 빽빽이 뒷받침**한다.
